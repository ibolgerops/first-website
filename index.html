Publish Your First Website

Before you begin: Have your website files ready, including a homepage named index.html

1. Create Your GitHub Account

  1. Visit github.com and select Sign up.
  2. Follow the prompts to choose a username and complete your account setup.
  3. Verify your email address when prompted, then sign in to GitHub.

2. Create Your Website Repository

  1. Select the + menu in GitHub, then choose New Repository
  2. Choose your account as Owner and name the repository first-website
  3. Select Public, turn Add README on, then click Create repository

3. Add Your Website Files

  1. Open your repository's Code tab, then select Add File (or the + beside the green Code button) and choose Upload files
  2. Upload index.html and any supporting CSS or image files. Keep index.html at the top level of the repository, not inside an extra project folder.
  3. Enter a short commit message describing your upload, such as "Add website files," then click Commit changes

4. Publish with GitHub Pages

  1. Open your repository's Settings tab, then select Pages in the sidebar.
  2. Under Build and deployment set Source to Deploy from a branch.
  3. Under Branch, select main and /(root), then click Save.
  4. Allow some time for publishing. Refresh Settings then Pages, then click Visit site to open your website.
